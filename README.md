# 🌱 GreenSight AI  
Smart Greenhouse Monitoring & Plant Health Assistant  
Group 9 — ENT207TC

GreenSight AI is an intelligent agriculture assistant created for experimental greenhouses and home gardening.  
It combines environmental monitoring, a built-in mini language model (LLM), and computer-vision-based disease detection for Solanaceae crops such as tomatoes, peppers, and eggplants.

This application was developed as part of ENT207TC, focusing on user-centered design, technical innovation, and entrepreneurial practice.

# 📱 Features

### 🌡 Real-time Environment Monitoring
- Temperature & humidity tracking  
- 24/7 plant condition visualization  
- Instant alerts when thresholds exceeded  

### 🤖 AI-Powered Planting Assistant
- Built-in lightweight LLM  
- Provides cultivation advice  
- Answers user questions  

### 🌿 Computer Vision Disease Detection
- Solanaceae disease identification  
- Upload image → instant analysis  
- Tested with sample dataset  

### 🧩 User-friendly Dashboard
- Clean UI  
- Simple navigation  
- Beginner-friendly design
